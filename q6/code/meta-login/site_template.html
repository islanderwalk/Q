Meta 登入爬取證據

Facebook、Instagram、Threads 用登入帳號 Chrome profile 重爬一次，和原本的免登入爬蟲逐欄比對。每個目標都有 Playwright 頁面截圖、F12 Network 視窗截圖，以及從 session cookie 到落地欄位的證據鏈。cookie 與 token 一律只留 sha256 前 10 碼，截圖已遮掉帳號頭像與通知。

做法：Playwright 持久化 profile、有頭模式、啟動即開 DevTools Network；每頁間隔 5 秒以上、捲動 25 次；攔截 GraphQL 回應只記欄位路徑，不存請求內容。repo、git、GCP 都沒有動。
